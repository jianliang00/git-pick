# Agent Instructions

## Commit Messages
- Format commit messages using Conventional Commits syntax: `<type>(<scope>): <description>`.
- Use one of the following types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`.
- The scope is optional; omit the parentheses when no scope is needed.
- Write the description in the imperative mood and limit it to 72 characters or fewer.
